# Agora Dental Appointment Reminder Assistant Demo

## 1. Overview

Hear a fictional Boston dental appointment reminder and discuss attendance, cancellation or rescheduling intentions without changing clinic records. This is one fictional dental appointment, not a patient record or evidence of an actual clinic visit. No patient lookup, appointment system, dialer, notification, calendar or external action is connected. Never claim an attendance response was saved, an appointment was changed or cancelled, or a message was sent. Do not disclose further details after a wrong-person response. Do not collect patient identifiers, medical history, insurance or payment information. Do not diagnose, invent clinical preparation rules or promise treatment outcomes. The caller may discuss preferences, but only the original configured appointment has a time.

## 2. Try the Demo

Use [local setup](https://github.com/AgoraIO-Community/agora-dental-reminder-demo/blob/main/README.md#run-it). Choose `Start dental reminder`, allow microphone access and try: “Please remind me of the dental appointment. I would like to discuss changing the time.” Ask for a verbal recap before ending. Each session ends after ten minutes. No real outbound phone call is placed.

## 3. Architecture & Tech Stack

Next.js, React, TypeScript, Agora Conversational AI, Agents SDK, RTC and RTM. The existing browser voice lifecycle is unchanged. Next.js signs tokens and starts/stops the managed Agent; no business database or external action is connected.

## 4. Prerequisites & Configuration

Use Node.js 24, pnpm 9.15.9 and an Agora project with Conversational AI enabled. Create `.env.local` from `env.local.example` only when absent. Set public `NEXT_PUBLIC_AGORA_APP_ID` at build/runtime and server-only `NEXT_AGORA_APP_CERTIFICATE`. Never expose the certificate in browser code. The default managed models need no separate vendor key.

## 5. Quick Start

```bash
pnpm install --frozen-lockfile
pnpm run doctor
pnpm run dev
```

Open http://localhost:3000. Preserve existing credentials. The planned npm creator is `npx agora-dental-reminder-demo@latest my-app`; a published version can differ from this local source.

## 6. How It Works

The start action fetches a combined RTC/RTM token and invites the Agent using requester_id and channel_name. Instructions are generated by `lib/agent-config.ts`. Tools remain disabled. Corrected details and simulation outcomes exist only in the current conversation; there is no saved result or cross-session memory.

## 7. Customize for Your Business

Edit `lib/agent-config.ts` for the role, workflow and guardrails, `lib/scenario-knowledge.ts` for fictional reference and generated dates, `lib/presentation.ts` for public identity, and `components/ScenarioFaq.tsx` for usage answers. `lib/runtime-profile.ts` owns model and voice defaults. Existing repository, npm package and Recipe identifiers remain stable.

## 8. Deployment & Validation

Follow [deployment instructions](https://github.com/AgoraIO-Community/agora-dental-reminder-demo/blob/main/README.md#deployment). Run `pnpm run verify`; Docker checks use `pnpm run verify:docker` separately. Inspect desktop/mobile pages, FAQ, and inline startup failure/retry. Synthetic tests and builds do not establish real model behavior, bilingual speech quality, hosted connectivity or actual business operations. Real speech acceptance is separate. No publication or deployment is performed by this source update.
